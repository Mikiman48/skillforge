# SkillForge

SkillForge is a modern learning and skills management platform designed to help learners, instructors, training academies, and organizations manage learning programs, courses, skills, progress, and professional development.

## Vision

SkillForge aims to provide a centralized platform for managing:

- Learning programs
- Courses and learning content
- Learner progress
- Skills and competencies
- Assessments
- Course completion
- Training operations
- Learning analytics

The platform is being developed as an independent product rather than as an extension of an existing Learning Management System.

## Core Features

- Course discovery
- User authentication and onboarding
- Course enrollment
- Learning content and activities
- Assessments
- Progress tracking
- Course completion
- Skills and competency tracking
- Instructor tools
- Academy administration
- Reporting and analytics
- Notifications
- Role-based access control

## Architecture

SkillForge follows a modular architecture with clear boundaries between:

- Frontend applications
- Backend APIs
- Application and domain logic
- Data persistence
- Infrastructure

The frontend communicates with backend services through defined APIs.

Business logic remains in the backend, while the frontend focuses on presentation and user interaction.

- `docs/architecture.md`
